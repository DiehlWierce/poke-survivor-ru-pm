## Инструменты (в `tools/`)
- `v5_index.py <scratchpad>` — карта символов; `v5_symdiff.py <v4dir> <файл> "<func X>" [v5|ours]` — нормализованный diff V4→V5 (или V4→наше) для символа.
- `v5_merge.py <v4dir> <файл> "<sym>"…` — применяет дельту V4→V5.1 к нашему символу (нераспознанные куски печатает как КОНФЛИКТ — их делать руками; `_abn("k")` → `abx.k` автоматически).
- `v5_splice.py <наш файл> "<sym>"…` — заменить символ телом V5.1 (только если наш == V4); `v5_append.py <наш файл> "<sym>"…` — добавить новый символ.
- После вставок: `perl -pi -e 's/[ \t]+$//; s/(\w): = /$1 := /' файл` (артефакты декомпилята). zsh/BSD: `sed -i` без суффикса не работает, `timeout` нет.
- Классы V5 `Hud/Cards/Minimap/Stick` у нас — файлы `scripts/ui/*.gd` (один уровень отступа меньше); для слияния выделяй тело класса в `<scratchpad>/v4ui|v5ui/scripts/ui/*.gd` (как делалось раньше) и вызывай merge с `V5ROOT`-логикой из скриптов.
