# Сравнение Poke Survivor и план переноса

Этот каталог сохраняет отчёт, план этапов 1–5, состояние и заметки сравнения BASE / UPSTREAM V5.3 / OURS 3.2.0 для контекста ветки `codex/portmaster-meta-1-5`.

- `REPORT.md` — выводы, классификация и приоритеты.
- `PLAN.md` — задачи этапов 1–5 и рекомендации по проверке/PortMaster.
- `STATE.md` — фиксация выполненной работы и релевантных коммитов.
- `notes/` — разведка, заметки по подсистемам, инвентарь файлов BASE/UPSTREAM и проверка релизного APK.

Релизный APK доступен по ссылке в `notes/10_v53_apk.md`; его SHA-256 и способ декомпиляции там же. Из-за размера и лицензий APK, восстановленные исходники и игровые ассеты в репозиторий не добавлялись. Пути к восстановленным скриптам в заметках обозначают источник/строку в локальном анализе APK.
