Проверка APK уточнила границы пяти изменений к реализации: (1) природы и (2) капсул способностей в APK не найдены; (3) APK уже позволяет бесплатно выбрать один стартовый приём через улучшение TM (`scripts/save_data.gd:249-253,278-300`; `scripts/menu.gd:4050-4115,4114-4140`), но не содержит инвентаря TM/обучения; (4) ежедневной тренировочной лавки нет; (5) второй приём после «Репертуара» выбирается случайно (`scripts/main.gd:2130-2150`). Наши обучение TM и ежедневный ассортимент — отдельные функции; выбор второго приёма нужно добавить рядом с селектором первого, не дублируя его.

Из релизных заметок V5.3 для PortMaster интересна заявленная экономия частиц/эффектов ради снижения лагов (`scripts/patchnotes.gd:21`). Влияние на нашем устройстве и конкретные файлы реализации не подтверждены; перед отдельной задачей нужен собственный профайлинг. Полный список изменений APK: `notes/10_v53_apk.md`.

## 5.3 унаследовал от BASE без существенных изменений

- Точное сохранение кода нельзя подтвердить: BASE — JS веб-игра, UPSTREAM — GDScript, а доступный UPSTREAM снимок имеет только четыре коммита. Значения нельзя считать «переносом без изменений» только по похожему поведению.
- Функционально общий слой врагов и волн: лимит около 64 активных врагов в базовом варианте, низкая плотность, масштабирование урона/XP и усиление при заполнении толпы (BASE `js/systems/spawner.js:14-24,92-109`; UPSTREAM `scripts/main.gd:3245-3275`; `ce57853` / `4f964fee`). OURS настроил handheld cap на 44 и добавил адаптивные изменения — сохранять OURS.
- В инвентаре общие пути и размеры: 13,468 путей BASE и UPSTREAM совпали по размеру. Хэши не сравнивались, поэтому содержимое и лицензии графики/аудио этим не подтверждены. Подробная таблица имён/размеров: `notes/07_asset_inventory.tsv`.

## Неясное и требующее решения

1. Уточнить происхождение исходников V5.3: release APK проверен, но V5.x source-теги по-прежнему указывают на commit `4f964fee`, подписанный как V4.0.
2. Уточнить лицензионный статус заимствования конкретных фрагментов: текущий BASE `ce57853` — после границы `b297089`, тогда как UPSTREAM LICENSE заявляет MIT для производного порта. До разрешения считать код и таблицы данных «только идеей».
3. Решить, достаточно ли пользы от персональных билдов (природа/способность/TM), чтобы оправдать новое состояние сейва, меню и баланс.
4. В OURS не найден tracked `bench_*`; точная производительность и размер экспортного PCK для кандидатов неизвестны. В будущем сравнивать headless Linux arm64 экспорт и замер на устройстве.
5. Для BASE assets сравнивались только пути и размеры, не хэши/содержимое; никаких ассетов к плану переноса не включено.
