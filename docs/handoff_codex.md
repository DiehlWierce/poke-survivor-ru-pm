## Проверка производительности

Для затрагивающих горячий путь шагов использовать `tools/bench_ab.sh <base-ref> [пары=3]`. Он сравнивает только изменённые `scripts/` файлы в том же worktree и с общим `.godot`, чередует порядок, запускает каждый Godot через `/private/tmp/poke-bench-lock.sh codex`, восстанавливает рабочие файлы при любом выходе и сверяет средние avg/p99, `bench_blank_frames` и `vis_missing`. Gate: avg после ≤ до × 1.03, p99 после ≤ до × 1.05, blank=0, vis_missing=0. Для изменений без горячего пути бенч не нужен.
