# Handoff: жалобы плейтеста 4–6 (грета, окна после легендарного, смена биома)

Ветка от portmaster. Коммиты: 510e2017, 2bc925af, b6f773d9 (+ этот файл). Mac M4, оконный запуск, `--keys-only`
(потолок 30 к/с, запекание в потоках как на приставке). Машина во время замеров была сильно загружена другими
агентами (load average 40–55): одиночные кадры 100–150 мс в «после» с маленьким «всего» в Prof — это шум машины.

## Цифры (до → после)

- Вход в грету, кадр входа: 65–87 мс → 43–48 мс; синхронных кусков 4 (≈41 мс) → 0. С медленными потоками (`--bakeslow 150`): 214 → 48 мс.
- Выход из греты: 57–75 мс → 40–45 мс (с `--bakeslow 150`: промежуточная версия 290 мс, исправлено в b6f773d9).
- Арена не готова (`--arenaslow 4000`): до — один кадр ждёт поток (секунды, без картинки); после — завеса в тот же кадр, худший кадр за 2,4 с ожидания 41–50 мс.
- Окна: уровень→вязь 2,26–2,33 с → 75–87 мс; вязь→мир 1,98–2,05 с → 0,45–0,63 с; между окнами уровней 40 мс (без изменений).
- Смена биома с медленными потоками (`--bakeslow 700 --bakejobs 1`): кадров полусмены 28 → 0. Во всех сценариях после: пустых кусков 0, кусков без объектов 0, полусмены 0.
- Совпадения (вход до/в кадр/после смены биома, насыщение 44–64 врага + босс + 120 орбов + 8 атак, пауза в переходе, босс+окна в момент смены, rush 5 боссов подряд) × режимы normal/daily/rush × стартеры 1/4/7/25/92 × свежее/прокачанное (`--maxup`) сохранение: тайм-аутов 0, залипаний 0, враги/орбы до и после греты совпадают, скрытых 0.
- bench_ab --seed 12345, 3 пары: средн 9,82/9,93 мс (−1 %), p99 35,3/35,7 (под нагрузкой). check_all: OK.
- Приставка (оценка ×4–6, по заметке bench_frame до ×40): вход был 0,3–0,5 с (до 3 с при ×40) + ожидание арены; теперь работа кадра входа ~10 мс Mac → 40–60 мс (до ~0,4 с при ×40), ожидание арены — под завесой.

## Не проверено

Приставка не мерилась. Пиксельная проверка полусмены (`--capture`) слабая: похожие палитры дают ложные срабатывания, а настоящую полусмену «до» она не поймала — надёжна проверка по состоянию кусков. Завесу глазами смотрел только по логу (кадры, флаг), не по снимку. Зависание rush на 4-м боссе — у другого агента; здесь 5 боссов подряд проходят.
