## Контекст платформы (важно для оценки)
- На приставке (`keys_only.gd`, autoload) все события джойстика отбрасываются: `keys_only.gd:259-262`. Кнопки приходят клавишами из gptokeyb: `portmaster/pokesurvivors/pokesurvivors.gptk` (up/down/left/right = стрелки, a=enter, b=esc, x=r, y=b, l1=q, r1=e, l2=z, r2=c, back=tab, start=esc).
- Поэтому весь слой `pad.gd` (переназначение кнопок, `STICK_*`, триггеры в `_z_poll`) работает только при подключённом джойстике на ПК. На целевом устройстве он не участвует.
- Свободных кнопок нет, а крестовина = движение. Прямой выбор приёма 1-6 с крестовины/триггеров на приставке невозможен без потери движения или Z/Dynamax.
- Свои механизмы OURS, с которыми надо стыковаться:
  - `quality` (Auto/Alta/Media/Baja, `save_data.settings.quality`) + `q_auto` + `_fx_cap()` (`main.gd:1285`, на hh `min(cap,96)`).
  - `Actor.lite = _hh()` (`main.gd:575`).
  - `pfx.lite` с кэпами 180/64 и шагом 30 Гц (`pfx.gd:6-8,33-36,167`).
  - Слияние чисел урона `DMG_TXT_MAX=12` (`main.gd:53,7871-7906`), только при `Actor.lite`.
  - Журналы `keys_only.gd`/`prof.gd`: `perf_census()` `main.gd:1396`, настройки в шапке `keys_only.gd:200,557`.
  - `max_fps` в настройках (`menu.gd:6940-6962`).
- Все новые строки интерфейса нужны во всех `data/lang_*.json` (ключи испанские). Для ru обязательно.
