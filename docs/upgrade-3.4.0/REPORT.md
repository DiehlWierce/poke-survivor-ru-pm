# Апгрейд 3.3.x → 3.4.0: различия с апстримом V5.6

Дата сверки: 2026-10-25. Наша база: ветка `portmaster`, `config/version="3.3.2"` (контент 3.3.1 + журналы 3.3.2).

## Источник и метод

- Релиз `JayElDragon/poke-survivor` **V5.6** (2026-10-22), `Pokemon.Survivors.5.6.apk`, SHA-256 `2e4cfbc9…5eba87` — совпадает с GitHub.
- Восстановлен GDRE Tools v2.7.4 (`--recover`, полный проект): 58/58 скриптов, 14 024 ресурса, 0 ошибок. Движок 4.7.2.
- Для честного диффа так же восстановлен APK **5.3** (тот же декомпилятор → одинаковое форматирование). Исходник 5.3 есть в `upstream/main` (`296fadc0`); тег `V5.6` указывает на тот же коммит, то есть исходник 5.6 **не опубликован**.
- Важно: в 5.6 спрятаны два неопубликованных релиза, **5.4 и 5.5** (крупный баланс). Запись «5.5» в `patchnotes.gd` сводит пункты 5.2–5.5.
- Код не копировался; декомпилят лежит только в scratchpad сессии.

### 8. Локализация

- Не хватает 131 ключа во всех `data/lang_*.json`. Сюда входят все новые строки из разделов 1–7 и 81 строка патчноутов 5.4–5.6.

## Конфликты с нашими системами

- **perf:** опцию 5.6 лучше ставить поверх нашей настройки «качество эффектов» в `save_data`, а не рядом с ней. Иначе будет два ползунка с одинаковым смыслом. Режим нужно писать в `perf_log` и `run_log`.
- **Ввод:** на хендхелде джойпад отключён, кнопки приходят клавишами (`keys_only.gd`). Всё из `pad.gd` проверять только на ПК.
- **Слияния:** у нас нет лимита за забег — это намеренное решение 3.3.2, апстрим не возвращаем.
- **Структура:** код у нас разнесён по `scripts/ui`, `scripts/game`, `scripts/util`. Номера строк апстрима переносятся только по смыслу.
- **Наши фичи вне апстрима:** натуры, капсулы способностей, TM, ежедневная лавка, второй стартовый приём. Новые цены улучшений (×0.6) затронут и их, баланс надо решить отдельно.
