# Отчёт по плейтесту на приставке (portmaster, хотфикс 3.1.1)

Ветка `portmaster`, все исправления слиты (четыре ветки агентов), затем совместная проверка на Mac M4
по пути приставки (`--keys-only`: lite, 30 к/с, запекание в потоках). Правило владельца — «нельзя ухудшать
игровой опыт» относительно `main` — проверялось сравнением с `main` и с базой до плейтеста `4519be21`.
Подробности по отдельным правкам: `docs/handoff_playtest.md`, `docs/handoff_vfx.md`, `docs/handoff_modes.md`.

Найдено при совместной проверке и исправлено:
- Бот матрицы считал ожидание под завесой греты «временем стоит» (в headless с `--fixed-fps` за 0,4 с ожидания
  потока проходят сотни кадров) → ложный TIME_STALL в 162/270 прогонах. Ожидание теперь меряется по часам,
  >5 с — RIFT_WAIT_LONG (c89285b7). Максимум в матрице — 466 мс.
- Шум dummy-рендера «Initializing already initialized RID / mem is null» (та же гонка, что известный `t is null`) —
  не провал (c89285b7).
- Не был закоммичен `scripts/ui/rift_veil.gd.uid` (404ecd7c).
- bench_events `--capture` снимает кадры входа и завесы (6110cedc).
