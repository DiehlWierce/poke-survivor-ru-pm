Основа: origin/portmaster bde672c8. Файлы Claude: scripts/main.gd, scripts/menu.gd, scripts/moves_data.gd, scripts/abilities.gd и вынесенные из них scripts/game/*.gd, scripts/ui/*.gd.

## Как проверялось

Каждый шаг: `--import`, `--quit-after 600 -- --keys-only` (счёт строк SCRIPT ERROR), `tools/pgcheck.gd` (хеш check), bench default и bench `--scenario run --prof`. HOME для godot каждый раз указывает на пустую временную папку. Mac (Apple Silicon), headless; на приставке не мерил.

Наблюдение: забег в bench run не детерминирован (итоги XP в двух прогонах базы разные: в орбы 10669 и 7841), поэтому сравнивать итоги забега бит-в-бит нельзя, только время кадра. Причина: `main._ready` зовёт `randomize()` и `world_seed = randi()` уже внутри `add_child`, поэтому `seed(12345)` в бенче не действует. Пробовал копию бенча (в scratch, tools/ не трогал) с `seed(12345)` на кадре 3: всё равно расходится к кадру 300 (стартовый покемон и мир уже случайные). `--die 60 --detdie` тоже недетерминирован: урон ходов и типы убитых разные.

Шум: в одной папке при одинаковом коде средн бег гуляет от 2,1 до 3,6 мс (±25 %), нагрузка забега случайная (снарядов в кадре 3300 от 14 до 93), машину параллельно грузят другие процессы. Допуск 3 % одним прогоном не проверить. Метод: `ab.sh` гоняет bench run попеременно «до шага» и «после шага» в ОДНОЙ папке (файлы scripts/ подменяются), порядок в парах чередуется; сравниваю средние по парам. Первые прогоны «база из основной папки против A1 из worktree» были ошибкой метода (разные кеши .godot) и не учитываются.

Предложение Codex/мердж-сессии (tools/ чужие): добавить в bench_frame.gd флаг, который ставит `seed()` до `main._ready` (например, через статический флаг, который main читает вместо `randomize()`), тогда бенч станет детерминированным и пригодным для проверки «поведение не изменилось» бит-в-бит.

### Заметки по шагам

- A1: `_hash` из main.gd и `ARENA.hsh` сравнены скриптом на 100 035 точках (30 000 малых координат, 70 000 случайных 64-битных, плюс крайние значения): 0 расхождений. Разница в формуле только в лишних масках `& 0xFFFFFFFF`, которые по модулю 2^32 ничего не меняют.
- B1: внутренние классы вынесены через `const Имя = preload("res://scripts/ui/имя.gd")` в main.gd, поэтому все `Имя.new()`, типы `var x: Имя` и `Имя.SC` в main не менялись. Тела классов перенесены без правок, только снят один уровень отступа. Заголовки разделов (`# --- ... ---`) перенесены к своим классам. Статику `Actor.lite`/`Actor.tick` и константу `TOWER_FLOORS` вынесенные файлы берут через `preload("res://scripts/main.gd").Actor` (циклический preload main ↔ ui). В Godot 4.7.2 это парсится и работает: проверено `--check-only`, запуском main.tscn на 900 кадров, бенчами и UI smoke. Имя `move_slots.gd` выбрано, чтобы не путать с `scripts/slots.gd` (гача, файл Codex).
- Инструмент проверки UI (scratch, не в репозитории): скрипт открывает карточки (смена, вето, выбор), даёт тост, паузу и смену размера окна 640x480 ↔ 1280x720, затем проверяет, что нет SCRIPT ERROR.
- A7 (is_instance_valid): хранимые ссылки уже защищены. `target` пересчитывается каждый кадр в `_update_player` до использования, освобождение врагов идёт через `queue_free` (отложенно до конца кадра); `tw_boss`/`tw_boss2` в `_update_tower` проверяются через `is_instance_valid`; в `_hurt_player` они сравниваются только с null (без обращения к полям). Правок по A7 не делал.
