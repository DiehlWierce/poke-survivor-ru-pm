## 1. Как получить исходники V5.0

1. `git fetch upstream --tags`. Если у upstream появились коммиты после `4f964fee` с кодом V5 — используй их и обычное
   слияние (ветка `port/v5` от `portmaster`, `git merge upstream/main`), шаги 2–3 ниже пропусти.
2. Иначе — восстановление из APK. **Скачивание APK и инструмента (GDRE Tools, github.com/GDRETools/gdsdecomp, сборка под
   Godot 4.7) требует разрешения владельца** — спроси, назови файлы, источник и размер. Сверь sha256 APK с указанным выше.
   Всё скачанное клади в отдельные пустые каталоги вне репозитория (например `~/ps_v5_src/{apk,tool,v41,v50}`), ничего из
   APK не запускай. Восстанавливай `v4.1` и `V5.0` одним и тем же инструментом.
3. Нормализованный дифф: восстановленный v4.1 (из APK 4.1) против восстановленного V5.0 даёт чистое изменение V5 без шума
   «пропали комментарии/формат». Сначала сравни восстановленный v4.1 с `main` (V4.0) по смыслу — это заодно покажет хотфикс 4.1,
   которого у нас может не быть. Затем создай ветку `upstream/v5-recovered` от `main`, примени туда **смысловой** дифф
   v4.1→V5 к читаемым исходникам V4.0 (сохраняя комментарии оригинала), закоммить с пометкой «восстановлено из APK».
   Новые ресурсы (спрайты, звук, видео, json) бери из V5 как есть; `.import`/`.godot/` кэш не коммить.
   Теперь есть настоящая трёхсторонняя база: `git merge upstream/v5-recovered` в `port/v5`.
4. Лицензии: проверь `LICENSE`/`CREDITS.md` V5 и сохрани атрибуцию (оригинал JPTER78, Android-порт JayElDragon); новые
   ресурсы с другой лицензией отметь в `portmaster/pokesurvivors/licenses/`.
