Статус: **этапы 0–3 выполнены, этап 4 (меню): Испытания и TM Gachapon готовы (см. «Сессия 2»), остальное не перенесено; 5–6 — частично.** Версия в ветке 3.2.0 (метка/сборка PortMaster не делались, ничего не пушилось).

## Перенесено
- Новые модули V5.1 (26 файлов): данные (`gachapon_data, challenges_data, fusions, kec_spr, evo_abil`), логика (`ach, challenges, gachapon, kecleon, textscale, touch_scroll`), эффекты (`vfx2, evo_fx, fusion_fx`), мир (`poi, rescue, alpha, hazard, cave, cave_int, lab_int, invasion, meteor, mewtwo, secret, daynight`).
- `main.gd`: 54 чистые дельты, 187 новых символов, 41 конфликт склеен (`tools/v5_merge.py` + ручные правки). Подключены: слияние ходов, эволюционные эффекты, Кеклеон (уклонение/феникс/магазин), события мира, день/ночь, испытания (`chal`), прицел, бомба стирает экран (боссы −30 % HP), `TRAP_R`=112, обратный отсчёт после меню, watchdog зависшего `choosing`/`time_scale`.
- `scripts/ui/*`: Hud (предметы, слияние, POI, строки испытаний), Cards (`GRACE`), Minimap, Stick, `pause_ui` (сводка, размер текста, прицел), `pad` (стик → навигация), `display`.
- `judgment` (Арсеус 5.1), `icons`, `vfx.sprite`/`pfx.slash`, данные `abilities/moves_data/types_data`, `save_data` (улучшения, `pull`, поля сейва — только добавлением, `SAVE_SCHEMA_VERSION` не менялся, подарок `gift_6h` безопасен для повреждённых сейвов), `lang_*` (+ключи V5.1, `lang_vi.json`, `vi` в `LANGS`), `patchnotes` 3.2.0 на 10 языках.
