### 2.3. Порядок и «стоп»-условия
Порядок: A целиком -> B1 -> B2 -> B5 -> B3 -> B4 -> B6 -> (C только по данным). После КАЖДОГО шага: smoke + бенч; если кадр хуже базы >3 % или любой тест красный - откат шага (revert своих правок), не продолжать. Не смешивать рефакторинг и изменение поведения в одном шаге.
